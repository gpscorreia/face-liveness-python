# Face Liveness MVP

Projeto pessoal para detecção de prova de vida (Liveness) usando Python, OpenCV e MediaPipe.

## Etapas do MVP
1. [x] Abrir a webcam utilizando OpenCV e exibir a imagem.
2. [x] Detecção facial.
3. [ ] Detecção de piscada.
4. [ ] Detecção de movimento da cabeça.
5. [ ] Sistema de desafios.
6. [ ] Resultado final de Liveness.

## Como executar

1. Ative o ambiente virtual:
   ```bash
   .venv\Scripts\activate
   ```
2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
3. Execute o script principal:
   ```bash
   python main.py
   ```
